# Diabetes Classification: Machine Learning Model Comparison

## Project Overview

This project focuses on predicting diabetes outcomes using machine learning classification algorithms. The main objective is to explore the dataset, apply appropriate preprocessing techniques, train different classification models, and compare their performance.

The project is developed as part of a hands-on machine learning learning journey using Python and scikit-learn.

## Dataset

The dataset contains medical and diagnostic measurements used to predict diabetes outcomes.

**Features:**
- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age

**Target Variable:** `Outcome`
- `0`: Negative
- `1`: Positive

Dataset file: `data/16-diabetes.csv`

## Project Objectives

- Perform Exploratory Data Analysis (EDA).
- Identify and handle potential data quality issues.
- Apply appropriate data preprocessing techniques.
- Train and compare multiple classification algorithms.
- Evaluate model performance using suitable classification metrics.
- Interpret the results and identify the strengths and limitations of each model.

## Machine Learning Algorithms

The following algorithms are planned for comparison:

- Logistic Regression
- Support Vector Machine (SVM)
- Gaussian Naive Bayes
- AdaBoost Classifier

Additional algorithms may be included during experimentation.

## Evaluation Metrics

Model performance will be evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Score
